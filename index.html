02projekt 2 · taskand-landing — strona jako usługa2 pliki · zero zależności

Chcesz, żeby strona „żyła” jak aplikacja? Wystarczą dwa pliki obok siebie: index.html (zapisz tę stronę: Ctrl+S / Plik → Zapisz jako) oraz Dockerfile albo serve.sh — oba do pobrania poniżej.

wariant docker — „bezpieczna apka w kontenerze”
nginx w Alpine, jeden plik skopiowany do obrazu, port mapowany. Zero pythona na hoście, powtarzalność, możesz puścić na serwerze. Uruchomisz też wersję z Docker Hub (gotowy obraz).
docker build -t taskand-landing . docker run -d -p 8080:80 --name taskand-landing taskand-landing # → http://localhost:8080
wariant bash — najszybszy start
jeden skrypt POSIX: wykrywa python3 → busybox httpd → python2 i serwuje bieżący katalog. Idealny do szybkiego podejrzenia; docker daje izolację i powtarzalność — bash do podglądu, docker na serio.
sh serve.sh 8080 # albo domyślnie bez argumentu # → http://localhost:8080 (python3 -m http.server)
02bootstrap v0.4 — pierwsze uruchomienie (tryb shell)docker run -it · 4 pytania · instalacja = Dockerfile-y
